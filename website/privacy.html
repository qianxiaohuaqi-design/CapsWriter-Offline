V1 · 数据与连接

你的文字，如何被处理。

本说明对应 V1 源码候选方案。实际发行应与所用版本一并核对；可在项目仓库查看完整源码和变更。

本地识别

本地语音模型在电脑上处理录音。首次下载模型需要连接清单中显示的托管来源；模型准备好后，本地识别不依赖上传录音。硬件推荐在本机检测，不要求注册账号。

你主动开启的 AI

AI 润色是独立的可选开关。启用后，识别文字和你允许的上下文、热词或选中文字会发送给你配置的服务。该服务的数据处理规则以其自身政策为准。未启用时使用本地识别结果；服务失败时保留原文。

下载与手动更新检查

下载模型会访问模型来源；手动检查更新会读取本项目 GitHub 发行元数据。网络服务通常会获知请求的 IP 地址等连接信息。更新检查不发送 API Key、录音、转写内容或个人配置，不自动下载安装程序。

保存在电脑上的资料

配置、热词、历史和转写结果在本地保存；录音是否保存由你设置。安装版使用当前用户的 LocalAppData/CapsWriter，Portable 使用便携目录内的 data 和 models。迁移或删除前请先退出应用并备份。

普通配置导出不包含密钥、录音、模型和历史。分享日志或诊断文件前，请检查是否包含你不希望公开的路径、文件名或手动填入的文字。应用不会自动上传诊断包。

卸载和网站

卸载默认只移除安装器拥有的程序文件，保留模型和个人数据。本静态网站不使用统计脚本、广告跟踪或账户系统；外部 GitHub 和微软链接适用各站点政策。

如需报告问题，请使用 项目问题页，不要提交私密录音、密钥或未经检查的完整配置。
