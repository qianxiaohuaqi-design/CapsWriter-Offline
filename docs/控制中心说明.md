# CapsWriter 控制中心使用说明

面向第一次使用桌面控制中心的用户，说明各页面的用途和推荐操作。

## 启动与退出

### 使用发布包

如果下载的是发布包，先解压：

- `CapsWriter-Full.zip`：完整版，内置本地 ASR 模型，解压后运行 `CapsWriter.exe`。
- `CapsWriter-Lite.zip`：精简版，不内置 ASR 模型；首次使用前需要下载模型并放入包内的 `models` 目录。

可以在控制中心“语音识别与硬件”页面打开模型配置指引，查看推荐模型、下载地址和模型目录入口。

### 从源码启动

从源码启动：

```powershell
python run_app.py
```

Windows 下也可以双击：

```text
启动 CapsWriter 智能控制中心.bat
```

启动器会同时管理：

- ASR 服务端：负责模型加载和语音识别。
- 听写客户端：负责快捷键、录音、识别结果处理和文本上屏。
- 控制中心 GUI：负责可视化配置。
- 托盘菜单：负责打开 GUI、启动缺失组件、重启和完全退出。

需要彻底关闭时，请使用托盘菜单或“服务与诊断”页面里的完全退出。

## 通用与交互

这里配置日常听写体验：

- 听写快捷键
- 长按对讲或单击录音模式
- 听写状态浮层
- 最终输出方式
- 输入输出兼容性选项

“直接写入”会在识别完成后把文本写入当前光标位置。“确认后写入”会先显示可编辑确认框，并把文本复制到剪贴板。

## 本地数据管理

这里集中管理本机生成的数据：

- 输入历史
- 听写日记
- 录音文件
- 转写输出
- 日志文件

清空输入历史不会删除录音、日记、转写输出、日志或配置。

## AI 润色与角色

普通离线听写不需要 API。只有启用 AI 润色或 AI 角色时，才需要配置 API。

推荐流程：

1. 新增一套 API 档案。
2. 填写服务商、Base URL、API Key 和模型。
3. 在润色或角色设置中选择该档案。
4. 只开启确实需要的 AI 功能。

内置角色包括翻译、小助理和大助理，也可以添加自定义角色。

## 热词与替换规则

`hot.txt` 适合固定热词替换，例如项目名、产品名、库名和技术词。

`hot-rule.txt` 适合正则替换，例如标点、换行、邮箱或固定格式文本。

不要把热词当作通用翻译系统使用。过度的中文到英文替换可能导致普通中文听写意外输出英文技术词。

## 语音识别与硬件

这里配置模型和运行策略：

- 本地 ASR 模型
- 识别语言
- 数字格式化
- 拼写格式化
- 繁简转换
- ONNX 后端
- GGUF 与 GPU 选项

模型列表只应显示本地已经放置完整的模型。

## 字幕转写

字幕转写用于把音频或视频文件转为文本和字幕。

常见输出：

- `TXT`：便于阅读和人工修改。
- `JSON`：包含时间戳，适合程序处理。
- `SRT`：通用字幕格式。
- `merge.txt`：合并后的全文。

页面支持单文件、批量转写，以及编辑 `TXT` 后结合 `JSON` 时间戳重建 `SRT`。

## 服务与诊断

这里用于查看和修复运行状态：

- ASR 服务端状态
- 听写客户端状态
- 控制中心状态
- 模型就绪状态
- 最近警告和错误
- 日志入口

常用操作包括启动缺失组件、重启服务端、重启客户端、打开日志和完全退出。

## 配置备份与迁移

备份页面用于迁移或恢复设置。

导出内容包括普通设置、热词、替换规则和 AI 档案结构。私有 API Key 默认不导出。

自动备份只覆盖配置文件，不备份模型、录音、日记、日志或转写输出。
