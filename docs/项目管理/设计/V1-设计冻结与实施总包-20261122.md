## 2. 冻结产品范围

1. 保留现役浅色视觉、八项导航顺序及全部成熟功能；第五项更名“模型中心”，保留高级 ONNX/GGUF、GPU、语言配置。完整新增深色适配后续处理。
2. 六步向导可跳过、可跨启动恢复；可靠硬件推荐一款模型，同时显示完整现有模型列表。首条真实下载闭环为 SenseVoice；来源、变体、许可、大小、SHA-256 未核验的下载不得伪造可用。
3. 首次明确选定模型在真实加载成功后启用；已有默认模型的用户只能手动确认切换。下载、校验、安装、加载与就绪分别显示。
4. 浮层编辑后当回合停止自动关闭，保留文字、所有输入模式、焦点保护和迟到 AI 防覆盖；AI 对新用户显式启用，普通导出/日志/安装包不含密钥。
5. 文件任务持久化、单项重试、独立产物；重试从文件开头处理，不承诺精确音频断点。源文件、源旁旧字幕、既有结果不被覆盖。
6. 关闭控制中心窗口且应用后台仍运行，模型下载必须继续；重开连接同一任务。完整退出安全暂停。转写仅在真正独立后台且可核验时继续，否则明确提示等待/安全停止。
7. 配置导入预览、预检、备份、读回和失败回退；热词非法规则和外部修改冲突拦截；基础脱敏诊断及清理范围预览。保留全部历史与用户数据。
8. 用户手动检查更新，说明版本、渠道与可信入口；不做静默自动更新。Windows 当前用户 EXE 安装包和 Portable ZIP 同源构建，均不预装大型模型；卸载默认保留数据，不默认自启。
9. 简中静态官网使用真实产品截图、真实构建元数据；未验证的下载按钮禁用。G7-T 为源码与技术准备，G7-P 为授权发布后的真实公共下载核验。

全部 C0 和 R2 指定基础 C1 是交付范围，C1 不代表可自行删去。延后：复杂自动更新、完整新增深色适配、多语言网站、Mac/Linux、云同步、专业字幕编辑器、预装大模型 Full 包。

## 3. 六项优化的可执行规则

### 3.1 首次设置与运行故障分离

保存 `setup_status`、用户明确选定的默认模型与当前 Worker 状态，不能用 `not ready` 反推首次用户。未设置用户进入向导；跳过/中断后在常规界面显示继续设置；已有模型加载中显示加载，加载失败进入修复。只有明确的首次设置候选且没有既有默认选择时允许自动启用。A 故障而 B 刚下载完成，仍不得自动从 A 换 B。

### 3.2 听写与长转写竞争

队列未开始的文件让听写优先；运行中的推理只在真实安全边界交接。不能中断的当前推理明确显示忙碌/等待，不得显示虚假录音或静默丢热键；提供等待或安全停止。不得为追求即时抢占粗暴终止未知进程。具体调度由现有引擎能力决定，不承诺未经证明的即时抢占。

### 3.3 重试与恢复

任务保存源文件身份、原模型和参数；重试默认沿用。模型不可用、源移动/变化时明确阻止并提示重新选择。任务 ID 稳定，每次运行有独立 attempt ID 和产物目录；成功后才更新结果指针，旧结果保留。迟到事件和重复点击不能生成重复运行或覆盖新状态。重开 GUI 先连接存活任务，只有确认无所属进程的旧运行记录标中断。

### 3.4 向导与后台可发现性

保持六步结构，但自动检测/校验/安装衔接减少重复确认；下载前显示字节大小、所需空间、保存目录。麦克风测试需主动触发，可跳过且标“未测试”。快捷键预填现有设置；首次关闭窗口一次性说明托盘与重开入口。托盘失败保留可访问控制入口。当前 A 可用与 B 下载可以同时展示。

### 3.5 提前验证打包

B1/B2 即准备最小 PyInstaller 产物并检查无模型启动、资源/数据路径、后台归属；完整安装/升级/卸载仍在 B4。不能在 Linux 源码检查后宣称 Windows 打包已通过。

### 3.6 单一交接、分阶段读取

恢复先读当前交接、本冻结总包、实际回执；按阶段读必要细则。AGENTS 恢复入口改为当前交接，旧 CHANGELOG 只作历史。一次完整授权连续推进 B0–B6，普通实现选择自主完成。
