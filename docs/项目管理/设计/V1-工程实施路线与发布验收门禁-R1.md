## 4. 测试矩阵重点

- 模型与启动：正常已有/完全无模型/文件损坏、Worker 加载中和已退出、端口属于无关程序、断开连接及重复 GUI/托盘。
- 下载：Range 不可用、ETag/来源变化、缓存截断、SHA 不符、失败安装、恶意压缩路径、下载中关闭 GUI 与完全退出。
- 听写：麦克风权限、中文/英文/IME、长按/单击、多快捷键、音频过短、文字上屏失焦、复制/剪贴板恢复、AI 迟到结果。
- 字幕：单/批量音视频、非 ASCII 路径、FFmpeg 缺失、无音轨、同名产物、取消重试/重启、TXT+JSON 新版 SRT。
- 配置：坏 JSON、部分应用失败、回滚失败、私有 Key 屏蔽、热词外部编辑冲突、清理路径软链接与兄弟目录。
- 安装/卸载：空 Win10/Win11、当前用户无管理员权限、不同安装路径、Portable 移动目录、更新后数据/模型/热词保持、用户拒绝清理数据。
- 官网：版本/哈希/下载链接真实，404 时禁用，未签名状态如实说明，手机和桌面布局及许可证材料。
- 每项标记是否自动化/真机/人工用户验收，有未测情况不能记为通过。实际模型许可和代码签名资格仍需正式发布前复核。
