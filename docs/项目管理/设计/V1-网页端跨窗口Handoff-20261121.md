保留 Windows NiceGUI/PyWebView 控制中心与八项导航、现有 SenseVoice/Fun-ASR-Nano/Qwen3-ASR/Paraformer、热键、两种录音/输出模式、浮层、历史、日记录音、热词/正则、可选在线 AI 和字幕/备份等。Installer 与 Portable 无大型权重，首启引导可信下载或导入。复用现有 Worker ready_event 而非将 PID/端口当就绪。保护原模型、配置、钥匙、历史、录音、媒体及字幕；下载验证、安全解压、模型切换回退、配置事务、转写隔离、进程归属/路径归属、MIT 和依赖许可、干净发行构建是关键。未验证来源/权利/哈希的模型不开放一键下载；未发布文件不伪造官网链接。
