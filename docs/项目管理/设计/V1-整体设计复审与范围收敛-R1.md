## B. 交叉冲突与统一建议

| 冲突/缺口 | 不采用的方案 | R1 建议的统一规则 |
| --- | --- | --- |
| 导航 7 个新入口 vs 现有 8 项 | 重建整个侧边栏 | 继续 8 项原导航；“模型中心”作为「语音识别与硬件」的**可选更名**，最终由用户确认。首次向导在现有 GUI 主内容区；官网不是控制中心新导航。 |
| 无模型时 ASR 退出 vs 首次引导 | 启动器在 ASR 失败后阻止 GUI | GUI 与 ASR 生命周期分离；无模型也能使用设置、历史、下载和向导；模型与热键的可用性由可信状态分别判断。 |
| `model_loaded=server_alive` / 托盘 PID 显示就绪 | 端口/PID 在线即绿色已就绪 | 模型安装完整性、Worker 当前实例加载状态、ASR 通讯与快捷键客户端分别建模；首页/模型中心/托盘/诊断共用同一真值源。 |
| 首次模型 vs 第二个模型启用 | 下载完都自动切换 | **首次成功安装且真实可加载的模型可自动设为当前**；后续新增模型不暗切，需确认且可恢复旧模型。 |
| 文件任务“恢复” vs 下载断点续传 | 识别中断后虚称从 67% 继续 | 下载按校验后可信源支持断点续传；转写任务仅持久化排队与完成元数据，异常退出后可从文件开头重跑、保留完成结果。 |
| GUI 关闭后后台持续任务 | GUI 内存 Task 就保证后台继续 | 后台所有权与任务持久层实际存在才承诺关闭 GUI 后继续；否则显式提示“关闭将中断”，禁止虚假后台状态。 |
| 输出保留 vs 旧 GUI 在源媒体旁写同名 `.txt` | 先写源目录再搬运 | V1 GUI 必须防止覆盖源目录现有文件（隔离工作区/安全临时目录/独立 task_id）；旧 CLI 另设兼容测试，不因 GUI 改造毁旧工具。 |
| 字幕 SRT 显示可用 vs 模型缺时间戳 | 无对齐能力仍写“高精度 SRT” | 按真实模型能力、必要辅助对齐模型与成功结果判定；否则引导安装辅助模型或降级 TXT；原用户格式设置不重置。 |
| 离线隐私承诺 vs 在线 AI | 宣传“所有数据永不联网” | 本地语音识别与可选在线 AI 明确区分；启用在线 AI 会向用户选定 API 服务发送相关文本，模型下载/检查更新另有网络访问。 |
| 备份导入 vs 私有 Key/数据 | 全量备份含 API Key/普通配置导入不可回退 | 配置导出采用安全允许列表，不含 Key、录音、历史；导入预检+差异预览+旧版备份+失败恢复；不能把普通明文 JSON Key 说成系统加密。 |
| 服务诊断“重启即修好” vs 录音/转写/下载中 | 一键杀端口 PID | 确认进程归属，限制重启范围；活动任务有中断提醒和明确授权，恢复需真实就绪信号。 |
| Windows Installer/Portable vs 旧 Full/Lite ZIP 代码 | 直接复用破坏模型目录并删除 LICENSE 的打包脚本 | 单一可信构建输入，两个发行渠道独立产物；修正目录/许可/敏感数据；Full 大模型包不列 V1 主发布。 |
| 项目旧逐阶段交接协议 vs AgentSpec 新模式 | 每完成 M1-B/M1-C 回网页端重新派单 | 本项目 V1 采用“网页端设计冻结 → 一次完整 Codex 交接 → 内部里程碑连续开发 → V1 集中用户验收”；各阶段测试证据和远端操作授权仍保留。 |

## C. V1 分级范围建议（不是用户最终裁定）

### C0｜首发门禁：缺一不可

- **C0-1 零模型 GUI**：正常进入控制中心；引导可跳过、恢复；显示可信模型安装、加载与听写状态。
- **C0-2 模型获取闭环**：至少 SenseVoice 的真实可信下载、暂停/恢复、校验、安全解压、安装、首次启用和失败无损恢复；已安装用户的旧模型与目录不被强制迁移。
- **C0-3 既有功能回归**：长按/单击全局快捷键、现有声波与文本浮层、直接写入/确认写入、热词/规则、历史、日记/录音（配置启用时）、文件单/批量转写与 TXT/JSON/SRT 能力、AI 档案/角色及设置备份；不凭 UI 演示代替真机运行。
- **C0-4 安全与数据保护**：不向错误焦点写文本、不覆盖源媒体旁旧字幕；配置、API Key、模型、历史、热词和旧用户改动有保留/备份；安装器、导出和诊断包不泄露秘密；需要删除时有精确范围。
- **C0-5 Windows 发行**：一套可复现、经真机验证的标准安装版和 Portable；当前用户安装（条件可满足时）与快捷方式、卸载入口；升级/卸载默认保留私人数据；包内 MIT + 适用依赖许可；旧本机 `build.spec` 受保护。
- **C0-6 官网最小交付**：静态落地页、真实截图、模型与安装指南、两版下载入口/版本/校验说明、隐私与许可证；下载链接必须来自真实已核验发行文件，正式公开发布/站点部署另需授权。
- **C0-7 验收**：自动测试与真实 Windows 录音/输入/下载/转写/安装/卸载路径，含错误、旧数据、版本和隐私检查；技术交付与用户验收分开。

### C1｜可纳入 V1 的次级完善，但不阻塞基本可用；开发前在整体设计冻结时选定

- 可信硬件推荐的多档可解释方案，以及各 ASR 变体的统一下载管理（必须在来源/许可/校验具备证据时才开放一键下载）。
- GUI 文件转写队列的可靠持久化、失败重试、任务恢复列表；**不承诺精准音频断点续识别**。
- 备份恢复分组选择、配置导入差异预览、热词编辑冲突检测、清理数据预览与脱敏诊断包。
- **手动检查软件更新与显式更新指引**；软件包更新可通过同渠道重新安装/替换并保留数据，真正全自动自升级不是首发门禁。
- 辅助模型按需安装、下载任务详细队列、基础无障碍与不同 DPI 的精修。

### C2｜明确推迟到 V1 后独立评估

- 不经用户确认的静默自动升级、复杂差分更新与完整原子回滚框架（首发须有安全手动更新与数据恢复路径）。
- macOS/Linux 版本、付费/账号/云同步、跨设备同步、实时云备份、复杂专业字幕时间轴编辑器。
- 多语言官网、额外大模型预装 Full 包、未经实测的 GPU 基准承诺、全自动在线性能分档。
- 将 API Key 迁移到 Windows Credential Manager/DPAPI 的架构变更可作为**评估项**，不允许因此在 V1 继续泄露密钥；现有明文存储需要明确展示与保护，工程上先堵导出、日志、打包泄露与权限漏洞。

**范围约束**：C1 优先级低于 C0，但其中一旦触及 C0 安全保障（如禁止覆盖旧字幕、导入失败回退），该必要安全部分归入 C0，不得当作可推迟的缺陷。

## D. 建议的界面交付标准（设计冻结门槛）

不以 7 个文字草案或 ChatGPT 内状态示意直接充当最终可编辑 GUI。沿用旧视觉后，无须重绘已成熟的全部设置页，但新增/改动的流程至少需要：

1. **现有 UI 截图/代码映射**：八项导航每一页列现有区块、新增/改造区块、保持不动区块；字体/颜色/间距/按钮尽可能引用已有 NiceGUI 样式，避免另建主题。
2. **关键页面/状态原型**：至少首次六步向导、模型中心（无模型/安装/已就绪/失败）、文件转写任务列表、确认浮层编辑保留、服务诊断健康/失败、安装器流程及官网响应式下载区；提供可执行的简洁 HTML 状态原型或页面规范及明确行为表。
3. **端到端状态流**：记录首装、旧版迁移、无网、下载中断、模型切换失败、录音/AI 失败、转写取消/重试、备份恢复、更新/卸载。每个动作需要前置条件、成功、失败、取消、重试结果及原数据影响。
4. **跨页面真值**：一个状态源分别服务顶部/托盘/模型中心/诊断，所有页面不会因缓存读数不同而相互矛盾。
5. **用户验收**：上述 UI 与完整 V1 产品边界和实现路线由用户明确确认，形成可追溯冻结版本；未确认项目列为开放决策，不擅自标记通过。
6. **唯一 Codex 包**：冻结后只发一份完整包，包含 AGENTS/AgentSpec、设计快照 SHA、UI 原型、任务顺序、接口约束、安全/测试/发布门禁、已知本机未同步 M1-A 与 W01 证据、原有 11 项本地改动保护、禁止擅自推送/上线/付费/重启/数据删除的权限边界。

## E. Codex 内部实施建议顺序（只作路线，不是当前派工）

- **B0 基线保护**：先核对本机分支、HEAD、未提交文件/哈希与旧 W01/M1-A；读取新 AgentSpec、现有 UI、设计冻结包、第三方许可。保持用户现存数据与自定义文件。
- **B1 核心可运行**：GUI 无模型启动、统一模型/Worker/客户端状态、故障恢复/托盘准确状态。
- **B2 模型与 UI**：来源核验、SenseVoice 下载/校验/安全安装、首次向导、模型管理；再扩展实际可支持的变体、硬件推荐。
- **B3 既有功能与数据保护**：听写浮层、输入窗口安全、热词/AI、配置导入/备份、文件转写隔离工作区、历史/隐私，完整回归。
- **B4 发行**：许可证/依赖/FFmpeg 审查、PyInstaller 产物、Inno Setup 候选、Portable，旧版本迁移与卸载安全。
- **B5 官网与分发准备**：真实截图、下载中心、版本/哈希/隐私/FAQ、下载链接只有在发行文件确实存在后才能激活。
- **B6 V1 全面测试与技术交付**：自动测试、真实 Windows 实机、卸载/重装、用户数据哈希、故障注入、诊断、发布审批材料；用户集中验收。**不因为完成某个内部阶段而反复请求网页端发新 Codex 任务**，仅重大阻塞/扩权例外。
