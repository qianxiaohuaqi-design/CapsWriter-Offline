- “语音识别与硬件”已有：ASR 下拉、语言设置、缺失文件提示、模型配置指引、ONNX 后端、GGUF GPU 与高级格式化参数；建议把此入口显示名改为“模型中心”（待用户确认），不改变其他七个导航入口，也不移除现有功能。
- 当前代码有 SenseVoice、Fun-ASR-Nano、Qwen3-ASR、Paraformer 四个 ASR 引擎；Qwen q4/q5 变体身份以本地 M1-A 实际清单为准。Qwen ForcedAligner / 标点是可选**辅助模型**，不能错列为主 ASR。

## 2. 页面纵向结构

1. **当前模型主卡**：当前活动 ASR 名称+准确变体、安装状态、运行状态、当前语言、真实可听写与否；根据状态呈现“查看详情 / 启动识别 / 重试 / 诊断”，但不在“端口在线”时写“就绪”。
2. **推荐模型卡**：仅在硬件信息可信且对应模型发行源、许可、校验与本机后端条件充分时，显示“推荐”及一句可解释理由；信息不足时显示“无法可靠推荐，可以手动选择”，不隐瞒不确定性。
3. **模型库列表**：已安装/可安装/需修复/待验证多类状态；提供按“已安装、全部、进阶”筛选。每个主 ASR 的型号/变体单独识别，避免同名混淆。
4. **下载任务区**：默认折叠但有全局进度入口；下载中常驻可见，显示真正的网络下载、校验、解压、安装、恢复阶段，避免“100% 下载”冒充“可以使用”。
5. **现有高级设置**：识别语言、ONNX 后端、GGUF/GPU、识别格式化、其他高级参数保持可访问；明确何时即刻生效与何时需确认重启。

## 3. 模型卡片字段及操作

| 字段 | 普通用户视图 | 展开详情 |
| --- | --- | --- |
| 标识 | 模型正式名称、可区别的变体 | 模型 ID、版本、发行来源及文件目录 |
| 能力 | 支持语言、适合场景；未知则说明 | 引擎类型、字幕/时间戳需要的辅助模型 |
| 资源 | 实际包大小、预计安装空间（有证据才显示） | 推荐硬件/支持后端、已知局限 |
| 安装状态 | 未安装 / 下载中 / 待校验 / 已校验 / 不完整 / 损坏 / 需审查 | 必需文件、清单版本、证据与缺失项 |
| 运行状态 | 未启动 / 加载中 / 已就绪 / 加载失败 / 已失联 | 关联当前 Worker 实例、启动时间与脱敏错误说明 |
| 操作 | 下载安装 / 导入 / 修复 / 启用 / 使用中 | 查看来源、打开目录、诊断；卸载是否首发另行确认 |

“文件齐全”“已安装”“运行就绪”不能共用一个布尔值；自动推荐和 UI 均须读取唯一可靠状态源（复用 M1-A 的定义）。

## 4. 核心用户流程

### A. 首次无模型
首页/向导进入模型中心 → 检测本机硬件与剩余空间 → 展示 1 个有依据的默认推荐，允许查看全部候选 → 选定发行版本、来源与真实下载大小 → 用户确认联网下载 → 下载/校验/解压/安装 → 首次有效安装后尝试加载 → Worker 确认就绪后才展示“可以开始听写”。失败可稍后再试，控制中心保持可用。

### B. 已有旧版手动放置的模型
扫描已有目录但不改写权重 → 识别兼容模型身份和缺失项 → 可用时保留原配置、允许正常听写；没有可信校验信息时将内容完整性标注为“未做内容校验”，不得因为缺少发行元数据而擅自删除或强制重装。

### C. 已有模型，想安装第二个
用户在模型库选另一模型 → 下载安装并校验到独立目录 → 安装完成后保留正在使用的模型不变 → 显示“已安装，是否切换？” → 用户确认后安全停止旧识别会话、加载新模型并检查真实就绪 → 成功后更新活动模型；失败时恢复旧模型/旧配置并报告，不能在识别进行中暗切。

### D. 网络失败、暂停和恢复
只有**一个活动下载**；其他明确显示“排队”。支持用户暂停、继续、取消（取消应有保留/清除暂存的明确选项）；GUI 关闭、托盘仍存活则可继续；完全退出应安全暂停并保存可恢复记录。恢复下载前检查来源、版本、Range/ETag 或同等可核对证据与内容完整性；来源不同/不支持续传时不得盲目拼接旧字节。下载中/校验中/安装中可返回其他页面。

### E. 导入与修复
允许选择本地可信模型包或文件夹 → 预览模型身份、目标目录、必需文件与冲突 → 校验（可信清单不存在则显示未经充分校验，不能虚报完成）→ 用户确认后安全导入；遇到未知布局，不自动移动或删除旧目录。修复先列明缺失/损坏证据，重试下载到暂存目录，校验后再原子替换应用自有的管理目录，旧模型有可恢复方案。

## 5. 重要状态与交互

| 场景 | 用户可见状态 | 允许操作 | 禁止的误导 |
| --- | --- | --- | --- |
| 无模型 | 尚无可用语音模型 | 选择/导入/稍后 | 声称程序无法启动 |
| 存在但未校验 | 发现模型文件，完整性尚未核实 | 查阅/试加载/导入可信包 | 仅凭 `exists()` 声称已验证 |
| 下载中 | 正在下载：具体进度、阶段 | 暂停/查看/使用其他功能 | 将下载100%标为已安装 |
| 校验失败 | 文件未通过校验，未启用 | 查看原因/重新下载 | 用损坏文件启动识别 |
| 安装已完成但未加载 | 已安装，识别服务未启动 | 启动识别 | 声称“已就绪” |
| 加载中 | 正在准备识别引擎 | 查看/取消可取消操作 | 启用听写按钮 |
| 已就绪 | 模型加载完成且当前 Worker 可用 | 正常听写 | 把历史进程状态当当前 |
| 加载失败/进程退出 | 模型启动失败或识别服务已中断 | 重试/诊断/恢复旧模型 | 仍显示绿色就绪 |
| 切换进行中 | 正在切换，当前听写暂不可用 | 查看进度/必要时恢复 | 在正在听写时静默中断 |

状态发生变化后首页、模型中心、托盘及服务诊断应引用同一可信快照；用户切换前需要告知可能暂时中断听写。历史记录与其他非 ASR 功能在无模型时仍可访问。

## 6. 硬件推荐规则（设计原则，非最终算法）

- 检测 CPU、内存、显卡/可用 VRAM、可用硬件后端、磁盘空间与模型来源要求。用户本机检测失败时提供保守方案，允许手选，绝不阻断软件整体启动。
- 不把“有 NVIDIA GPU”自动等同于 CUDA/TensorRT 可用；需检查实际运行时依赖和引擎兼容。
- 只展示可解释、由证据支持的推荐理由，标明性能可能因设备、驱动、后端而变化。
- 先以 SenseVoice-Small 打通可信的下载、校验与加载闭环，再把另三种 ASR 及 Qwen q4/q5 变体纳入同一接口；**不要将未通过发行/许可审查的模型显示为一键可安装**。
- Qwen ForcedAligner 等辅助模型在文件转写的字幕能力中按需提示安装，不能与主识别模型混为一谈。

## 7. UI 细节建议（待确认）

- 模型中心沿用现有控制中心的左侧导航、右侧白底卡片、浅色默认与深色主题，不重做全局布局。
- 顶部主状态卡使用当前状态，不用“已安装”代替“可以使用”；缺模型时显示一个清楚的入口。
- 推荐区采用**一款主推荐 + 查看全部模型**，高级选项折叠，减少新用户选择负担；旧用户可直接切换到已安装列表。
- 每张模型卡优先显示名称、能力、状态、主操作；详情才展示来源、许可、校验、包大小、技术参数。
- 下载区用一个持续可查看的任务区域展示队列和恢复，关闭 GUI 不应抹去任务。
- 不自动切换第二个模型；不自动删除手动安装的未知文件；模型移除/卸载界面是否列入 V1 尚需专门确认。
- 导入错误/空间不足/权限不足/无网络/来源变更/哈希不符/下载中断/加载超时都必须给出可恢复操作。
