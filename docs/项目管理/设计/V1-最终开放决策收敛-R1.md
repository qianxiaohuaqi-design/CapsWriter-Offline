> 2026-11-21。网页端推荐方案，待用户集中批准。非正式设计冻结、非 Codex 实施指令。依据上一设计快照 ddd20970e60602b239a4f8e6d9df02ccb16112cb。用户已确认保留现有外观与成熟功能、先集中完成设计再一次正式交接 Codex；本文件其余建议不冒充逐项批准。

## 建议收敛表

| 决策 | 推荐方案 |
| --- | --- |
| 导航 | 原八项及顺序不动；第 5 项“语音识别与硬件”更名“模型中心”，保留语言/ONNX/GGUF/GPU 等高级设置 |
| 视觉 | 继承当前 NiceGUI/PyWebView 浅色卡片和橙色强调；源代码明确 dark_mode(value=False)，深色完整适配不作为 V1 新增强制门禁，不移除实际已存在的主题功能 |
| 首启 | 无可用模型时主动引导六步，支持跳过、恢复；旧有可用模型直接进入常规 GUI |
| 推荐 | 一个有证据的推荐加完整候选列表，优先 SenseVoice；硬件检测/后端实际可用性、可信源、变体、许可和校验未确认时保守手选，不能保证性能 |
| 安装/切换 | 下载→校验→安全安装→真实 Worker 加载；首个可用模型自动启用，后续仅用户确认后切换，失败恢复旧模型并验证 |
| 模型删除 | 首发不强制新增复杂卸载模型功能；若纳入，仅程序拥有且非活动目录，二次确认，未知/手动模型默认只读 |
| 听写 | 保留快捷键长按/单击、直接写入/确认模式、声波/文字浮层。修改文本后停止自动关闭；目标失效或浮层异常安全保留可复制结果，不误粘贴 |
| 文件转写 | 原页内任务列表、独立任务结果、单项重试、持久化清单；中断后从文件起点重跑，不声称音频精确续传。源文件/旧字幕不覆盖；SRT 基于真实时间戳，保留 TXT+JSON 重建 |
| 后台 | 尽量使模型下载由托盘/Launcher 所有，关 GUI 仍可继续；文件转写仅在实测独立后台可用时承诺继续，否则明确提示中断并保存清单，完全退出安全暂停/取消 |
| 在线 AI | 保留原档案/角色与配置，新用户显式启用，失败保留原始 ASR，解释文本外发；Key 不出现在普通导出/日志/诊断/发行包 |
| 配置/数据 | 导入预检、差异预览、备份、读回与回滚；热词非法正则和外部修改冲突保护；清理范围独立、默认保护所有原数据 |
| 更新 | 手动检查更新和安全同渠道升级；不要求静默/差分自动更新 |
| 发行 | Windows Installer + Portable ZIP 同源构建，均无内置大型模型；Inno Setup + PyInstaller 优先候选，当前用户安装且默认不开机自启，卸载默认保留个人数据 |
| 官网 | 轻量静态简中站，真实截图、版本/哈希/许可/隐私/下载说明；未发布文件禁用按钮；公开部署、Release 与付费签名等另行授权 |

## 首发范围建议

- C0 全部保留：无模型 GUI、可信 SenseVoice 模型下载安装及真实加载、现有功能回归、安全/隐私、Installer/Portable、基础官网、G0–G8 实际验收。
- C1 推荐纳入基础硬件推荐、可信变体入口、任务持久化/单项重试、导入预览/回退、热词校验和冲突处理、手动检查更新、必要诊断与清理预览。复杂批量管理/高级性能分档/完整深色/大型架构变更不阻塞首发。任何 C0 安全保障不能因 C1 延期而缺失。
- C2 延至 V1.1 或以后：新完整深色适配（非删已有主题）、复杂无感升级、多语言官网、额外预装模型包、Mac/Linux、云同步/账号、复杂专业字幕编辑器。DPAPI/Credential Manager 是否采用由兼容与安全评估决定，不能将现有明文 JSON 说成加密。
- 不改变既有 ASR EngineFactory、NiceGUI/PyWebView 和成熟功能；优先复用 Worker ready_event，新增薄协调层。新任务存储按本机 M1-A 与实际成本择 SQLite 或原子文件，不强制迁移旧库。
