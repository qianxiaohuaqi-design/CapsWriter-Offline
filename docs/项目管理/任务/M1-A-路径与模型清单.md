# M1-A｜路径契约与模型清单基础层

- **状态**：已确认待实施；当前非活跃任务。等待 W01 结果与用户明确开始实施的授权。
- **前置**：阅读根 AGENTS、本目录 README/当前交接、M0 摘要；核对真实本地分支/HEAD/原 11 项改动及 build.spec。
- **目的**：先建立可复用的目录与模型状态契约，随后再开发下载器、硬件推荐、首次引导。

## 允许范围（得到实施授权后）

1. 统一应用资源、用户数据、模型、下载缓存、配置/私有配置、日志和历史路径；源码、旧便携版、模拟安装版三种布局均明确，不迁移实际用户数据。
2. 为现有四种 ASR 定义模型 ID、版本、变体、必需文件、能力、来源、哈希/许可（未知留空且阻止未经校验声称“已验证”）。
3. 定义未安装、部分安装、待验证、已验证、损坏/不兼容的**安装状态**，与加载中、就绪、失败的**运行状态**分开。
4. GUI 与服务端引用可复用模型状态接口，但不进行整页 UI 改造。保留现有引擎推理与 Python 配置兼容。

## 禁止范围

- 不在本阶段实现下载器、硬件打分、首次启动引导、多变体并存、安装器。
- 不改写或移动现有模型权重，不覆盖或重新生成私有配置/历史/热词。
- 未经授权不安装依赖、不启动重启业务服务、不推送或部署。
- 不擅自恢复或清理原 11 项改动与备份。

## 验收门槛

- 各路径模式单测：中文路径、空模型目录、不可写目录、相对路径和打包资源优先级。
- SenseVoice/Qwen 原有模型目录不变，能够通过旧式“必需文件存在”检查，但无可信校验时**不得冒充内容完整**。
- 模型元数据/状态接口可用且 GUI、服务端定义一致；测试与错误信息不包含个人密钥。
- 记录修改文件与提交、测试结果、未覆盖的真实模型加载项和 11 项保护。
- 按 [回执规则](../README.md) 准备交付，最终仍待用户验收。
