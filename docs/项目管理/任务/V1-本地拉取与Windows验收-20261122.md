3. 对原工作区只做 `fetch`、`show`、`diff` 等读取；**禁止 reset、clean、强制 checkout、直接 pull 或复制覆盖原目录**。不把原 11 项修改、私人资料或外部二进制一起上传。
4. 在新 worktree 中试用；若示例路径/分支已有内容，另取新名称，不删除或复用未知目录。

PowerShell 示例，在已核对的原仓库中执行：

```powershell
git status --short
git log -1 --oneline
git show --stat e7cc1e2
git fetch https://github.com/qianxiaohuaqi-design/CapsWriter-Offline.git feat/capswriter-v1-20261122
$V1SourceSha = (git rev-parse FETCH_HEAD).Trim()
git show --no-patch --format=fuller $V1SourceSha

```

把 `$V1SourceSha` 与用户交接词/总回执中的 SHA 对照；如远端在交接后多了提交，先查看差异再接续。对本地 M1-A 与新源码按语义比较，在新 worktree 中保留必要能力，避免叠加两套路径/清单/状态实现。不要在看效果之前把未审阅的旧工作区全部合并。

## 3. 先把真实界面打开

进入新 worktree，使用 Windows x64、Python 3.11 的独立环境：

```powershell
py -3.11 -m venv .venv-v1
.venv-v1\Scripts\python.exe -m pip install -r requirements-v1.txt
.venv-v1\Scripts\python.exe -m pip check
.venv-v1\Scripts\python.exe -m unittest discover -s tests -p "test_v1_*.py" -v
.venv-v1\Scripts\python.exe run_app.py
```

若旧版仍占用 6016/6017，先确认是否有录音、转写或下载正在进行，再使用旧版自己的“完全退出”。不得杀死未知端口进程。首次试用沿用新 worktree 的数据根；不要把 `CAPSWRITER_DATA_DIR` 指向原来正在使用的数据。

没有模型时控制中心也应打开。通过模型中心下载首个 SenseVoice，或登记现有模型的完整目录（只读取原文件）。不要为了试用复制/覆盖旧模型。加载状态必须来自真实 Worker，文件存在和端口监听均不足以显示“就绪”。

首先向用户展示真实 Windows 控制中心：保留原浅色视觉和八项导航，模型页为“模型中心”。截取通用页、模型中心、向导、字幕任务、服务诊断和编辑浮层的实际画面；截图不得出现密钥、个人识别文本或私人路径。现仓库官网截图是历史产品截图，不当作本次 Windows 测试截图。

## 4. 连续完成本地验证与修复

### 启动、模型与后台

- 验证无模型、已有模型、选中模型缺失/损坏、Worker 崩溃、旧 PID、未知端口和重复启动。
- 六步向导跳过/重开恢复；已有用户不弹强制向导；麦克风测试可跳过，未测试不能显示通过。
- 下载前真实来源/许可/大小/目录；校验与加载区分。首个明确候选成功加载才提交默认，之后手动确认切换；原模型失败不能因另一下载完成而自动切换。
- 下载中关闭 GUI 后应继续，重开连接同一 owner/任务；首次关闭提示返回入口；托盘失败仍保留控制入口。
- 完全退出必须等下载暂停、转写安全停止；待返回的听写/AI 结果不能被重启或切换中断。候选加载失败恢复原设置及自定义逐文件路径。

### 听写、AI 与转写

- 实测长按/单击、全部现有输入模式、中文/英文/IME、剪贴板、焦点变化、自动回车及过短录音。错误焦点必须停止自动写入并保留结果。
- 编辑浮层后永久停止该回合自动关闭；空文本、换行、改回原文、迟到 AI 和新录音不能覆盖编辑。
- 新用户 AI 默认关闭；启用后使用用户配置的提供商。测试角色及历史功能，日志/导出不能泄露密钥。
- 真实 Worker/WebSocket + FFmpeg 验证单/批量音视频、取消等待安全边界、重开连接活动任务、断开模型变中断、单项重试沿用原模型和参数。
- 每次 attempt 独立；源文件与同名旧 TXT/JSON/SRT/MERGE、旧成功结果在失败/取消/重试后哈希保持不变。没有时间戳时不伪造 SRT；重建 SRT 生成新文件。
- 实测听写与文件竞争：正在运行的推理显示忙碌，仅在安全边界交接；不保证即时抢占。

### 数据、配置与恢复

- 配置导入先预览，确认前文件变化时阻止；半写入/损坏 journal/回滚失败保持证据并恢复，不能静默重置。
- 热词非法正则、错误替换组与外部修改冲突保留编辑内容；已有有效运行规则保持。
- 清理只删除预览确认的未变化文件及应用拥有的非活动结果；不能删除源媒体、模型、兄弟目录、链接目标或未知文件。
- 诊断摘要只含允许字段；验证原密钥不在备份导出、普通日志、安装包或截图中。

### 提前打包与完整发行候选

尽早执行：

```powershell
.venv-v1\Scripts\python.exe tools/build_v1.py --minimal --output build/v1-smoke-01
```

核验新生成的最小包无模型启动、资源/数据/模型根、窗口与后台路径。此包缺少未核验外部运行库，不作完整发行。

随后按 `packaging/README.md` 用真实来源、版本、SHA-256 和许可证核验 FFmpeg/ffprobe、原有三个 GGUF 引擎的所需 DLL；不可用同名但 ABI 不兼容的 DLL 替代。完成统一 PyInstaller onedir、EXE 安装器、Portable ZIP 与 SHA 清单。在 Win10/Win11 的干净用户环境检查安装、升级、卸载、中文/含空格路径、Portable 移动和默认保留用户数据。

基础静态站已在 `website/`；实际 Windows 截图和通过验证的构建元数据就绪后补齐 G7-T。公开文件还不存在时，按钮继续禁用；只有授权发布并核验公开下载字节后才完成 G7-P。
