## 实际下载与安装

使用本次 `DownloadManager` 直接获取上游 HTTPS 包，完成 433,798,984 字节下载、SHA-256 对照、路径/链接/展开大小预检、安全临时解压、三文件检查、文件级哈希与同卷原子安装；最终状态 `completed`。包内目录为 `Sensevoice-Small-ONNX/`，与清单一致。旧手动模型目录未写入。

模型与测试音频仅存在隔离测试目录，不进 Git。下载由独立管理器线程拥有；实际 GUI 关闭后的存活由协调器集成测试/Windows 回归另行记录。首次试探后缀 Range 得到 HTTP 501；普通 GET 成功。因此不能宣称该网络对所有 Range 用法均支持。代码遇到不支持 Range、ETag 不同、Content-Range 不符会从头下载，而不会混拼缓存。

## 真实 CPU 推理

使用 [上游固定提交的公开 test-fun.mp3](https://raw.githubusercontent.com/HaujetZhao/SenseVoice-ONNX/4d7bce67e86b4049db1a58a6c2e2ecd34dfefd9c/test-fun.mp3)，84,140 字节；SHA-256 `ba5f8a9db8665afb48f1be359d4faef615dc7679165303f1e291da488469aafa`。解码后 55,200 个 16 kHz 采样，时长 3.45 秒。

现有 `SenseVoiceInference` 使用 CPU 加载真实下载的模型：加载约 2.107 秒；推理约 0.202 秒；生成 15 个带时间戳的单元。无额外热词时的原始输出：`那我来测试一下，放ASR nanono。`。这是加载与非空语音识别闭环证据，**不是专有名称准确率验收或性能保证**，也没有把原文整理成“正确转录”掩盖模型原始结果。

可复现入口：

```powershell
python tools/verify_sensevoice.py --data-dir C:\CapsWriter-Test\data --model-dir C:\CapsWriter-Test\models --download --accept-model-license --fetch-test-audio
```

参数明确触发联网，缺省只验证已经存在的模型；可以改用 `--audio` 指向自选测试音频。请使用隔离目录，不覆盖原工作区。
