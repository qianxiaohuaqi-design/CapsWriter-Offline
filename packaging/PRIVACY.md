# 隐私与数据说明

- 本地语音模型在本机处理录音；模型文件首次下载需要联网。默认服务绑定本机回环地址。
- 在线 AI 润色为显式开启的可选功能。启用后，会向你配置的服务发送识别文字，以及你主动允许的上下文、热词或选中文字；请查看该服务的隐私政策。
- 手动检查更新访问本项目的 GitHub Release 元数据。程序不携带 API Key、录音、转写内容或个人配置进行该请求，不自动下载或执行更新程序。
- 模型下载访问清单中显示的模型托管来源。下载请求会向对端透露网络请求通常所需的 IP 地址等信息。
- 配置、热词、输入历史、录音（主动启用时）和转写产物保存在本地。普通配置导出不包括 API Key、模型权重、历史、录音和输出。
- 安装版的个人数据位于当前用户 LocalAppData/CapsWriter。Portable 的 data/models 随目录迁移；移动或删除前请先完全退出并备份。
- 日志与诊断应当脱敏，但分享之前仍应检查是否含有私有路径、文件名或手动填写的信息。应用不会自动上传诊断包。
- 卸载默认保留个人数据与模型。删除个人数据需要用户针对明确范围的操作，安装器不会递归清空数据目录。
